- [ ] VOLFS 面板：每分钟量柱，红/绿/灰按大单方向着色
- [ ] 主力追踪面板：紫色净流入累计面积图
- [ ] 页面每 30s 自动刷新数据，无需手动操作
- [ ] 断开 westock 数据源时自动降级东财，页面不报错
- [ ] 日志写入 logs/deepthink_YYYYMMDD.log
